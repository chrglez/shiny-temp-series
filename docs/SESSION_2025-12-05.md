## Notas Técnicas

### Problema de Layout Identificado
El Waiter de `{waiter}` package causaba que el contenido principal se estrechara al ~33% del ancho cuando se ejecutaba "Run Analysis". El spinner no se mostraba visualmente pero el layout se alteraba.

**Solución temporal:** Deshabilitar Waiter completamente.

**Solución permanente sugerida:**
1. Usar `shinycssloaders::withSpinner()` en los outputs específicos
2. O usar `shinybusy` package como alternativa
3. O simplemente no usar spinner si el análisis es rápido
